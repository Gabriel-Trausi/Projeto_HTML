Texto

Os títulos em HTML vão de h1 a h6 e seguem uma ordem de importância. O h1 é o título principal da página, enquanto o h6 representa o nível menos importante. Normalmente, quanto maior a importância do título, maior é o tamanho da fonte exibida pelo navegador.

Parágrafo

No HTML, a tag <p> é utilizada para criar parágrafos. Ela organiza o texto em blocos separados, tornando a leitura da página mais clara e agradável.

Marcação

No HTML, a tag <mark> é usada para destacar uma parte do texto, funcionando de forma semelhante a um marca-texto. Ela é útil para chamar a atenção do leitor para palavras ou informações importantes.

Exemplo: marcação


Formatação de texto

A tag <small> é utilizada para exibir uma palavra ou um trecho de texto em tamanho menor. Ela pode ser usada para destacar observações, detalhes ou informações complementares ao conteúdo principal.

Itálico

A tag <i> faz com que uma palavra ou trecho de texto seja exibido em itálico. Ela é usada para dar destaque visual a expressões, termos estrangeiros ou pensamentos.


Sublinhado

A tag <u> é utilizada para sublinhar uma palavra ou trecho de texto. Ela pode ser empregada para enfatizar informações importantes ou para indicar links em alguns contextos.


Negrito

A tag <strong> é usada para destacar uma palavra ou trecho de texto, exibindo-o em negrito. Ela indica que o conteúdo tem grande importância dentro da página.


Listas

As listas em HTML são utilizadas para organizar informações de forma estruturada. Existem dois tipos principais de listas: ordenadas e não ordenadas.

Lista ordenada

As listas ordenadas são criadas com a tag <ol> e exibem os itens em uma sequência numérica.

Lista não ordenada

As listas não ordenadas são criadas com a tag <ul> e exibem os itens sem uma ordem específica.

li

A tag <li> é utilizada para criar itens em listas em HTML.


Links

Os links em HTML são criados com a tag <a>, que permite criar hiperlinks para outras páginas da web ou para recursos dentro da mesma página.


Quebra de linha

A tag <hr> é utilizada para criar uma linha horizontal que serve como um divisor entre diferentes seções do conteúdo.


sub

A tag <sub> é usada para exibir um texto em formato de subscrito, ou seja, abaixo da linha normal do texto. Ela é comumente utilizada em fórmulas químicas, equações matemáticas e notações científicas.


sup

A tag <sup> é utilizada para exibir um texto em formato de sobrescrito, ou seja, acima da linha normal do texto. Ela é comumente utilizada em fórmulas químicas, equações matemáticas e notações científicas.


blockquote

A tag <blockquote> é utilizada para exibir uma citação de um texto externo, geralmente com recuo e itálico.


font

A tag <font> é utilizada para alterar a fonte do texto. Ela permite especificar o tipo de fonte, o tamanho e a cor do texto.


del

A tag <del> é utilizada para exibir um texto como excluído, geralmente com uma linha através do texto. Ela é comumente utilizada para mostrar alterações em conteúdo.


abbr

A tag <abbr> é utilizada para definir uma abreviação ou sigla, permitindo que o usuário veja a forma completa ao passar o mouse sobre o texto.
